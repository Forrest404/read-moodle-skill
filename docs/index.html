read moodle skill

Ask Claude about your Moodle: what's due, what an assignment actually asks for, this week's readings, your grades and feedback.

It reads Moodle through Moodle's own API, the same one the official Moodle app uses. It only reads. It can't submit, post or change anything. Built for UCL. Other universities' Moodle sites may work if they allow the Moodle app.

Set up

You need a Mac and Claude Code. Open Claude Code and paste this:

Install https://github.com/Forrest404/read-moodle-skill for me. Read SETUP.md and follow it step by step.

Claude does the setup. You'll be asked to:

  1. log in to Moodle in your browser as usual, and click Open when it asks to open MoodleKey;
  2. pick your modules from a list and confirm your term dates;
  3. connect Notion, if you want to.

About five minutes. Restart Claude Code afterwards so the commands appear.

What it does

/todayDaily briefing: what's due, what to do today, this week's sessions and readings, new announcements.
/deadlines [days]Everything due in the next 14 days, submitted or not.
/assignments [module]All assignments with due dates, status and grades.
/brief <assignment>Reads the brief, attachments and marking criteria, and tells you what you actually have to do.
/module <code> [week]A module's week: sessions, slides, readings, announcements.
/grades [module]Grades, with a short summary of written feedback.
/planBreaks your deadlines into steps and adds them to your calendar (and Notion, if connected). It asks before adding anything.
/ask <question>Anything else on Moodle. You can also just ask in normal words.

What it can see and change

Reads from Moodle, using your own key: your courses, deadlines, assignment briefs and files, week pages and readings, announcements, your submission status, grades and feedback.

Never submits, uploads, posts, replies, marks anything done or changes settings on Moodle. The script refuses any Moodle function that could change something. It never asks for or sees your password.

Adds to your Mac:

  • ~/read-moodle-skill: the code, your settings (config.json) and downloaded briefs (files/)
  • ~/.claude/skills/: the commands above
  • ~/Applications/MoodleKey.app: a small helper, built on your Mac, that catches the key when you click Open
  • Keychain: your Moodle key, saved as read-moodle-skill

Only if you choose: a Notion page that /today overwrites and a Notion database that /plan adds rows to, and calendar events you import from /plan.

No servers, accounts or tracking. Moodle data goes to Claude only when you ask something, like anything else you ask Claude.

If something breaks

Run python3 -I ~/read-moodle-skill/moodle.py doctor. It checks each part and says how to fix it. If your key stops working (for example after a password change), run the same command with login instead of doctor.

Update or remove

Update: cd ~/read-moodle-skill && git pull && ./install.sh

Remove: ~/read-moodle-skill/uninstall.sh && rm -rf ~/read-moodle-skill
